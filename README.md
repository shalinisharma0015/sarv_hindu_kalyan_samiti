# सर्व हिन्दू कल्याण समिति — Responsive Website

यह एक multi-page responsive static website है, जो केवल HTML, CSS और JavaScript पर आधारित है।

## Pages
- `index.html` — Home
- `about.html` — समिति के बारे में
- `activities.html` — गतिविधियाँ
- `membership.html` — सदस्यता
- `donation.html` — दान जानकारी
- `news.html` — समाचार/अपडेट
- `contact.html` — संपर्क

## Folder structure
- `assets/css/style.css` — styles, responsive layout and animations
- `assets/js/main.js` — mobile navigation, scroll reveal, interactive UI and demo form handling
- `assets/images/` — image notes / location for local images
- `assets/icons/` — icon notes / location for local icons

## Run locally
1. ZIP extract करें।
2. `index.html` को browser में खोलें, या VS Code में Live Server extension इस्तेमाल करें।
3. Google Fonts और Unsplash images के लिए internet connection आवश्यक है।

## Important
- यह frontend-only project है; इसमें backend, database, admin panel या online payment gateway नहीं है।
- Forms अभी demo/front-end interactions हैं। Submit करने पर वास्तविक data server पर save नहीं होता।
- Live करने से पहले समिति का सही logo, verified contact details, registration details और approved activities जोड़ें।
- संस्था की पुष्टि के बिना किसी सेवा/गतिविधि को चालू बताकर प्रकाशित न करें।
